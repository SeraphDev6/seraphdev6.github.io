Accessibility statement

Accessibility isn't a compliance checkbox for us — it's where we started. That has to include our own website.

Our commitment

SeraphDev builds assistive and accessible technology for a living, including software designed with and for neurodivergent users. We hold our own site to the same standard we bring to client work.

Conformance target

This website is built to conform to the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA. In practice, that means we design and test for:

  • Sufficient color contrast for text and interactive elements
  • Full keyboard operability, with visible focus indicators on every interactive element
  • A logical heading structure and landmark regions for screen-reader navigation
  • A "skip to content" link and consistent, labeled navigation
  • Meaningful text alternatives for images, and decorative images marked as such
  • Respect for the prefers-reduced-motion setting, so animation never gets in the way
  • Content that reflows and remains usable on small screens and at high zoom

Ongoing work

Accessibility is a practice, not a one-time audit. We test with keyboard-only navigation and screen readers, and we treat any barrier a visitor hits as a bug to fix — not an edge case to defer.

Found a barrier? Tell us.

If any part of this site is difficult to use with assistive technology, we want to know so we can fix it. Reach out through our contact form with the page and what got in your way, and we'll respond promptly.

This statement reflects the current state of seraphdev.com and is reviewed as the site changes.
